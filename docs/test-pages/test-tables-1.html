    See the stories in readable data

    Each table on this page is a shape the DynamicRounding extension meets on real pages. Read one as a puzzle, or check it as a test.

    For anyone Solve a puzzle Look at a table, simplify it, and work out the story in the numbers. Open the data patterns or the story at any time, and click a title again to hide it. Start puzzle 01 →
    Tester's notes

    One fixture per kind of table the Chrome extension handles, plus the kinds it leaves alone. Load the unpacked extension, allow file URL access (or serve this page over localhost), and check each section against its stated expectation. Details sit in HTML comments next to each fixture.

    Every expectation assumes the default settings unless a step says otherwise: first row and first column excluded, currency and percent on, dates on at year granularity, times off. A table pillbox is the small on/off control at a table's top-right corner.

    23. Cells the page rewrites

    Tester's notes

    The page changes the values of each table in this section after its table pillbox is pressed on, the way a live dashboard or a scrolling grid does. Reload the page to start any part again.

    Expect: a table pillbox at load on 23a's two tables, 23c's grid, 23d's table, and 23e's table. The extension simplifies each change within a moment, and a restore shows the values the page last wrote.

    23a. One native table and one grid holding the same values

    When a button below is pressed, the page rewrites the same cell in both tables, so the two results sit side by side.

    1. Pull the sidebar's two offsets apart: largest numbers at -1, all other numbers at 0. The effect of the Add a row button shows only at unequal offsets.
    2. Press both table pillboxes on, then each button below. Check each result, then press the table pillbox off and check the restore.
    • Write a new number: the page writes 953,877 into South, Q2. Expect: the cell shows 953,877 simplified on both tables, and each cell's hover text shows 953,877. Restore shows 953,877 and removes the hover text.
    • Write a round number: the page writes 400,000 into East, Q1. Expect: the cell shows 400,000 and is no longer simplified: no hover text, and restore leaves 400,000.
    • Write a word: the page writes n/a into Central, Q3. Expect: the cell shows n/a with no hover text, and restore leaves n/a.
    • Rewrite one piece: the page writes 15,118 into the italic part of West, Q3. Expect: both numbers in the cell show simplified, the bold one from 281,745 and the italic one from 15,118. Restore shows 281,745 and 15,118.
    • Redraw the original: the page writes the cell's own original, 1,482,391, back into North, Q1, as a page redraw does. Expect: the cell shows simplified again within a moment.
    • Add a row with a larger value: the page adds a Global row of values above 12,000,000. Expect: on both tables the other cells keep their text, including the North row (1,500,000), and the Global values round like the largest values, 12,000,000 and 13,000,000. A failure shows every cell changing when the one larger value arrives.
    • Swap the column set: the page replaces the headers and the first five rows, as a page that loads a different query result into the same table. Expect: the extension detects a new table. It shows the original of the new values with the table pillbox off, and the sidebar shows the default settings for it, so pressing its table pillbox simplifies it under the defaults. The sidebar's active table becomes the new table only when this table was the active one.
    • Rewrite as the table pillbox is pressed: on the next table pillbox press on either table, the page first writes 925,006 into that table's South, Q1, in the same moment as the press. Press it with both tables on. Expect: the restore shows 925,006 in that cell and the originals everywhere else.
