DynamicRounding table test page

One fixture per kind of table the Chrome extension handles, plus the kinds it must refuse. Load the unpacked extension, allow file URL access (or serve this page over localhost), and check each section against its stated expectation. Details sit in HTML comments next to each fixture.

Shipped defaults: first row and first column excluded, mixed cells on, currency and percent on, dates on at year granularity, times off. A pillbox is the small on/off control at a table's top-right corner.
