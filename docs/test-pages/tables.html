DynamicRounding table test page

One fixture per kind of table the Chrome extension handles, plus the kinds it leaves alone. Load the unpacked extension, allow file URL access (or serve this page over localhost), and check each section against its stated expectation. Details sit in HTML comments next to each fixture.

Every expectation assumes the default settings unless a step says otherwise: first row and first column excluded, mixed cells on, currency and percent on, dates on at year granularity, times off. A pillbox is the small on/off control at a table's top-right corner.

23. Cells the page rewrites

Each table in this section changes its own values after the extension simplifies it, the way a live dashboard or a scrolling grid does. Reload the page to start any part again.

Expect: a pillbox at load on 23a's two tables, 23c's grid, and 23d's table. The extension simplifies each change within a moment, and a restore shows the values the page last wrote.

23a. One native table and one grid holding the same values

Every button rewrites the same cell in both tables, so the two results sit side by side.

  1. Pull the sidebar's two offsets apart: largest numbers at -1, all other numbers at 0. The Add a row button shows its effect only at unequal offsets.
  2. Press both pillboxes on, then each button below. Check each result, then press the pillbox off and check the restore.
  • Write a new number writes 953,877 into South, Q2. Expect: the cell shows 953,877 simplified, and the native cell's hover text shows 953,877. Restore shows 953,877.
  • Write a round number writes 400,000 into East, Q1. Expect: the cell shows 400,000 and is no longer simplified: no hover text, and restore leaves 400,000.
  • Write a word writes n/a into Central, Q3. Expect: the cell shows n/a with no hover text, and restore leaves n/a.
  • Rewrite one piece writes 15,118 into the italic part of West, Q3. Expect: both numbers in the cell show simplified, the bold one from 281,745 and the italic one from 15,118. Restore shows 281,745 and 15,118.
  • Redraw the original writes the cell's own original, 1,482,391, back into North, Q1, as a page redraw does. Expect: the cell shows simplified again within a moment.
  • Add a row with a larger value adds a Global row of values above 12,000,000. Expect: the new row shows simplified on both tables, 12,000,000 and 13,000,000. The native table simplifies every cell again against the new largest value, so the North row, the largest values until now, drops to the coarser rounding (1,500,000 becomes 1,000,000), and its hover text still shows its own originals. The grid keeps the max magnitude it took at its first simplification: its other cells stay as they were, and the Global values take the rounding of the largest values.
  • Swap the column set replaces the headers and the first five rows, as a page that loads a different query result into the same table. Expect: the extension detects a new table. It shows the new values raw with the pillbox off, and the sidebar shows the default settings for it, so a press simplifies it under the defaults. The sidebar's active table moves to the new table only when this table was the active one.
  • Rewrite as the pillbox is pressed arms the page. The next pillbox press on either table first writes 925,006 into that table's South, Q1, in the same moment as the press. Press it with both tables on. Expect: the restore shows 925,006 in that cell and the originals everywhere else.

23d. The pass measurement and the cell cap
